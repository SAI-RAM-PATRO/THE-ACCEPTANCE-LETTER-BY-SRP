# The Acceptance Letter — VS Code Version

## Open and run from VS Code

This is a React + Vite project.

### 1. Open the folder
Extract the ZIP and open the `the-acceptance-letter` folder in VS Code.

### 2. Open VS Code Terminal
Use:

**Terminal → New Terminal**

### 3. Install dependencies

```bash
npm install
```

### 4. Start the website

```bash
npm run dev
```

Vite will show an address such as:

```text
http://localhost:5173/
```

Ctrl+Click that address in VS Code, or copy it into Chrome.

### Important
Do NOT double-click `index.html` to run the React app. Use `npm run dev`.
